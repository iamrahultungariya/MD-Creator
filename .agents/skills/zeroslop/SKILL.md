## Phase 1: Context & Category Analysis

Classify the target interface into one of these archetypes:
1. **SaaS / Web Application:** Dense, split-pane, keyboard-navigable, high-density telemetry.
2. **Developer Tool / CLI Web:** Terminal-inspired, high-contrast monospace metadata, zero marketing fluff.
3. **Editorial / Publication:** Asymmetric Swiss typography, high-contrast serif/sans tension, paper tones.
4. **Physical Product / Hardware:** High-resolution photography, technical datasheets, sticky spec tables.
5. **Transactional / E-Commerce:** Clear value anchors, minimal friction, progressive disclosure.

## Phase 3: Autonomous Design System Synthesis

Before writing components, derive the design tokens mathematically using [`references/design-system-math.md`](references/design-system-math.md):
- **The 60-30-10 Palette:**
  - 60% Canvas: Base `#09090B` (Dark) or `#FAF8F5` (Light).
  - 30% Structural Surfaces: `#111113` with `border-white/[0.07]` and top specular highlight `shadow-[inset_0_1px_0_rgba(255,255,255,0.06)]`.
  - 10% High-Contrast Accent: e.g., Emerald `#10B981` / text-emerald-400 / `bg-emerald-500/10`.
- **The 8pt Spatial Grid:** All spacing must be multiples of 8px (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`).
- **The Nested Radius Formula:** $\mathbf{R_{\text{outer}} = R_{\text{inner}} + \text{Padding}}$. Never use uniform radii on parent and child!
- **Optical Typography Scale:** Display text (`tracking-[-0.035em]`, `leading-[1.08]`), Body (`max-w-[65ch]`, `leading-[1.6]`), and mandatory `tabular-nums` on all numbers.

## Phase 4: The 6 Modern 2026 Layout Blueprints

Never default to generic AI bento cards or centered stacked heroes. Choose one of the battle-tested blueprints in [`references/layouts-2026.md`](references/layouts-2026.md):
1. **The "Exposed Hairline" Architectural Grid:** Continuous 1px outer lines (`border-x border-white/[0.07]`) with corner `+` crosshairs.
2. **The "Zero-Marketing" Live Sandbox Hero:** 30% crisp header + 70% live interactive micro-workspace (markdown/code playground).
3. **Asymmetric 7:5 Swiss Editorial Split:** 7-column giant editorial heading + 5-column bottom-aligned dense subcopy with tabular metrics.
4. **The "Single-Workflow Zoom" Cropped Bleed Hero:** 1.25x magnified single active UI component nicely cropped at boundaries.
5. **Seamless Cell Matrix (Anti-Bento Grid):** Flush cells divided by `gap-px bg-white/[0.07]` with subtle hover luminance shift.
6. **Sticky "Index & Spec Sheet" Homepage Layout:** 3-column sticky numbered navigation index + 9-column technical datasheet.

## Phase 5: Pre-Flight Declaration & Delivery Gate

### 1. The Pre-Flight Aesthetic Spec (MANDATORY)

```markdown
> **Aesthetic Spec Declaration:**
> - **Surface Palette:** Canvas `#09090B` -> Surface `#111113` -> Elevated `#18181B` | 1px border-white/[0.07]
> - **Typography Scale:** Display `text-5xl tracking-[-0.035em] leading-[1.08]` | Body `max-w-[65ch] leading-[1.6]` | Tabular nums active
> - **Layout Blueprint:** Blueprint 1 (Exposed Hairline Architectural Grid with Corner Crosshairs)
> - **Density & States:** High-density, strict 8pt grid, 100% 4-state completeness (Loading, Empty, Error, Overflow)
```

### 2. The Mandatory Delivery Gate Checklist
Run this gate before declaring the work complete. Every item must PASS:

- [ ] **Hard Gate:** Zero em dashes (`—`) in UI copy. No fake statistics or testimonials. Minimum 44×44px touch targets. All buttons have real `onClick` or `href` destinations. Full keyboard navigation (`Tab`, `Enter`, `Escape`).
- [ ] **Purpose Gate:** Zero unmotivated gradients, glows, or glassmorphism. No icons in colored rounded boxes. No card-inside-card nested borders.
- [ ] **UX Laws & Resilience:** Verified against all 35 UI/UX Laws in [`references/ux-laws-handbook.md`](references/ux-laws-handbook.md).
- [ ] **4-State Completeness:** Component explicitly handles **Empty State**, **Skeleton Loading**, **Error State**, and **Long Text Truncation (`truncate min-w-0`)**.
- [ ] **Motion Check:** No `transition-all`. Hover/focus micro-interactions capped at 120ms–180ms. Framer Motion springs configured to `stiffness: 400, damping: 30` (snappy) or `stiffness: 300, damping: 28` (layout).
